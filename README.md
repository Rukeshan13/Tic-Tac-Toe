# 🎮 Tic Tac Toe Game

A simple two-player Tic Tac Toe game developed using **Python**. Players take turns placing X and O on a 3×3 game board. The first player to get three marks in a row, column, or diagonal wins!

## 🚀 Features

- Two-player gameplay (X and O).
- Interactive 3×3 game board.
- Automatic winner detection.
- Draw detection.
- Input validation to prevent invalid moves.
- Option to play again.

## 🎯 How to Play

1. The game starts with an empty 3×3 board.
2. Player X makes the first move.
3. Player O takes the next turn.
4. Enter the position you want to mark.
5. Get three marks in a row, column, or diagonal to win.
6. If all positions are filled without a winner, the game ends in a draw.
